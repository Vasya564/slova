# слова

Гра-пошук слів: дванадцять слів сховані у сітці з літер, їх треба знайти й провести по буквах — мишкою або пальцем.

Три рівні: 9×9 (рядки й стовпчики), 11×11 (+ діагоналі), 14×14 (+ слова задом наперед). Слова між рівнями не повторюються.

Грати: **https://vasya564.github.io/slova/**

Статична сторінка без збірки — `index.html`, `styles.css`, `game.js` (керування) і `puzzle.js` (розкладка слів у сітці). Сітка генерується наново при кожній грі, тож двічі однакової не буде.
